# ZAMKE (잠깨)

> An interaction-driven system that triggers instant alertness whenever needed — not passive alarms.

👉 [Download on App Store]  https://apps.apple.com/kr/app/id6762582070

---

## 🔥 Key Feature: Jolt Mode (화들짝 모드)

A high-intensity wake-up system combining:

- 🎧 **Horror-inspired sound design**
- 🎮 **Mission-based interaction**
- ⛔ **Forced engagement (no easy snooze)**

ZAMKE is not a typical alarm.  
It actively **forces the user to wake up through interaction and psychological tension**.

---

## 🎧 Sound Design Philosophy

Unlike conventional alarms, ZAMKE focuses on **audio-driven awakening**:

- **Ajaeng (Korean traditional instrument)** for raw, organic tension
- **Layered ambient drones** (wind, forest, low-frequency pressure)
- **Warning signals & chaos layers** to create urgency

> Designed to trigger **instinctive alertness**, not gentle waking.

---

## 🧠 Core Concept

> “Waking up is not a button — it is an action.”

ZAMKE transforms waking up into a **mission-driven experience**:

- You cannot passively stop the alarm
- You must complete tasks under pressure
- The system uses sound + interaction to break sleep inertia

---

## 🎯 Signature Mechanic

### Reaper Gaze

A tension-driven mechanic that forces the user to avoid visual fixation,
interrupting passive perception and triggering immediate alertness.
